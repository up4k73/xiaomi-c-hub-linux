# Xiaomi C-HUB для Linux

Управление **Xiaomi Desktop Speaker Pro Set** через оригинальный интерфейс
C-HUB: подсветка, эквалайзер, режимы звука, громкость и выбор входа.

[English](README.md) · [Подробная установка](docs/INSTALL.md)

![C-HUB в Linux](docs/images/lighting.png)

## Скачать

- [**AppImage для Linux x86-64**](https://github.com/up4k73/xiaomi-c-hub-linux/releases/latest/download/Xiaomi-C-HUB-Linux-x86_64.AppImage) — скачайте и запустите. Если файловый менеджер попросит, разрешите выполнение файла.
- [**Установщик для Debian / Ubuntu**](https://github.com/up4k73/xiaomi-c-hub-linux/releases/latest/download/xiaomi-c-hub-linux_amd64.deb) — откройте в установщике программ, затем запустите Xiaomi C-HUB for Linux из меню.
- [Архив переносимой версии](https://github.com/up4k73/xiaomi-c-hub-linux/releases/latest/download/xiaomi-c-hub-linux-x86_64.tar.gz) — распакуйте и запустите файл xiaomi-c-hub-linux.

**Node.js, npm, Windows и ручное извлечение файлов Xiaomi не нужны.**

При первом запуске приложение само получает около **40 МБ** файлов оригинального
интерфейса с серверов Microsoft, проверяет их и открывает окно C-HUB.
Для этой однократной подготовки нужен интернет. Затем интерфейс хранится
локально и работает без повторной загрузки.

Подключите колонку USB-кабелем. Установщик .deb настраивает доступ к устройству.
В переносимой версии при необходимости появится кнопка **Enable USB access**:
она запросит системное подтверждение и настроит доступ только для этой модели.

## Возможности

RGB, яркость, эффекты, десять полос EQ, режимы звука, громкость, входы,
звуковые уведомления и таймеры самой колонки. Запись считается успешной после
подтверждения и независимого чтения значения из устройства.

Кнопка **Refresh** перечитывает состояние после подключения колонки или
использования её физических кнопок. Обновление прошивки, сброс и перезапуск
устройства не поддерживаются. Системные настройки звука и микрофона приложение
не меняет.

Проверено на Debian 13 / KDE X11 с устройством 2717:d007: RGB, яркость и EQ
напрямую; RGB через USB-хаб в оригинальном интерфейсе. Остальные настройки
не все проверены на реальном оборудовании.

## Для разработчиков

~~~bash
git clone https://github.com/up4k73/xiaomi-c-hub-linux.git
cd xiaomi-c-hub-linux
npm ci
npm test
npm run package
~~~

указаны в [описании сборки](docs/SOURCES.md).
